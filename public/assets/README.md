# Assets Directory

## Video File Required

Place your football match video file here:
- **File name**: `hero-football.mp4`
- **Recommended specs**: 
  - Resolution: 1920x1080 or higher
  - Format: MP4 (H.264)
  - Length: 10-30 seconds (will loop)
  - Content: Football match with a player about to shoot

You can use any football match video or download a free stock video from sites like Pexels, Pixabay, or Unsplash.

The component will automatically fall back to a gradient background if the video is not found.
